## 📸 Project Overview
An exploration of the geopolitical, technological, and human shifts that defined the 20th century through the lens of global conflict. This web-based photography portfolio project analyzes the interconnected timelines of World War I and World War II. It examines how industrial-scale warfare dismantled empires, accelerated technological innovation, and established the modern international order, while highlighting the lasting socio-economic legacies that shape contemporary global relations.

### Key Features
*   **Curated Historical Galleries:** Chronologically organized chapters covering major wartime events and post-war reconstruction.
*   **Responsive Portfolio Layout:** Fully optimized for mobile, tablet, and desktop viewing environments.
*   **Semantic Data Structures:** Clean component architectures using isolated containers for modular navigation and socials.

## 🚀 Getting Started

Follow these steps to clone this project locally and view the web portfolio on your computer.

### Prerequisites
You only need a modern web browser (like Google Chrome, Microsoft Edge, or Mozilla Firefox) and Git installed on your machine.

### Installation & Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory:**
   ```bash
   cd War
   ```
3. **Open the project:**
   * Double-click the `index.html` file in your file explorer, OR
   * If you use VS Code, run `code .` and launch it using the **Live Server** extension.
